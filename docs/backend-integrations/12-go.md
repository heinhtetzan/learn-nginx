# Go (Golang)

Configuring Nginx as a reverse proxy for Go web applications (built with standard `net/http`, Gin, Fiber, Echo, or Chi).

---

## Architecture Overview

```mermaid
flowchart LR
    Client["Client Browser"] -->|HTTPS (443)| Nginx["Nginx Reverse Proxy"]
    Nginx -->|Static Files\n(/static/*)| Disk[("Static Assets Cache")]
    Nginx -->|Proxy Pass\n(http://127.0.0.1:3000)| GoApp["Go Compiled Binary\n(Gin / Echo / net/http)"]
```

---

## Go Systemd Service

Create `/etc/systemd/system/goapp.service`:

```ini
[Unit]
Description=Go Web Application
After=network.target

[Service]
User=www-data
Group=www-data
WorkingDirectory=/var/www/go.example.com
ExecStart=/var/www/go.example.com/server
Restart=always
RestartSec=5
Environment=PORT=3000
Environment=GIN_MODE=release

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now goapp
```

## Nginx Reverse Proxy Configuration

Create `/etc/nginx/sites-available/go.example.com`:

```nginx
upstream go_app_pool {
    server 127.0.0.1:3000;
    keepalive 64; # High keepalive pool for high-throughput Go services
}

server {
    listen 80;
    listen [::]:80;
    server_name go.example.com;
    return 301 https://$host$request_uri;
}

server {
    listen 443 ssl;
    listen [::]:443 ssl;
    http2 on;
    server_name go.example.com;

    ssl_certificate /etc/letsencrypt/live/go.example.com/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/go.example.com/privkey.pem;

    client_max_body_size 20M;

    # Direct static file serving (offloads Go runtime)
    location /static/ {
        alias /var/www/go.example.com/static/;
        expires 30d;
        add_header Cache-Control "public, immutable";
        access_log off;
    }

    # Reverse proxy to Go application
    location / {
        proxy_pass http://go_app_pool;
        proxy_http_version 1.1;
        proxy_set_header Connection "";

        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;

        # Keep connection open for streaming/SSE if needed
        proxy_buffering on;
        proxy_buffer_size 16k;
        proxy_buffers 4 32k;
    }
}
```
