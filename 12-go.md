# Go

Configuring Nginx as a reverse proxy for a Go web application.

---

## Folder Setup

- Domain: `go.example.com`
- Go app binary: `/var/www/go.example.com/app`
- Backend port: `3000` (configurable in your Go app)

Go web servers (using `net/http`, Gin, Echo, Fiber, etc.) listen on a port directly. Nginx proxies public traffic to that port.

---

## Go Service Setup

Create a systemd service at `/etc/systemd/system/app.service`:

```ini
[Unit]
Description=Go Web Application
After=network.target

[Service]
User=www-data
WorkingDirectory=/var/www/go.example.com
ExecStart=/var/www/go.example.com/app
Restart=always

[Install]
WantedBy=multi-user.target
```

Enable and start:

```bash
sudo systemctl enable app
sudo systemctl start app
```

---

## Nginx Configuration

Create `/etc/nginx/sites-available/go.example.com`:

```nginx
server {
    listen 80;
    server_name go.example.com;
    return 301 https://$host$request_uri;
}

server {
    listen 443 ssl;
    server_name go.example.com;

    ssl_certificate /etc/letsencrypt/live/go.example.com/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/go.example.com/privkey.pem;

    location / {
        proxy_pass http://127.0.0.1:3000;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }

    location /static/ {
        alias /var/www/go.example.com/static;
        expires 7d;
        add_header Cache-Control "public, immutable";
    }

    client_max_body_size 10M;
}
```

---

## Enable the Site

```bash
sudo ln -s /etc/nginx/sites-available/go.example.com /etc/nginx/sites-enabled/
sudo nginx -t
sudo systemctl reload nginx
```

---

## Static File Optimization

Go apps can delegate static file serving to Nginx for better performance:

```nginx
location /static/ {
    alias /var/www/go.example.com/static;
    expires 7d;
    add_header Cache-Control "public, immutable";
}
```

This offloads asset delivery from the Go binary, leveraging Nginx's efficient static file handling.

---

## Key Config Lines

| Directive | Purpose |
|-----------|---------|
| `proxy_pass http://127.0.0.1:3000;` | Forwards to Go application |
| `location /static/` | Serves static assets directly via Nginx |
| `expires 7d;` | Caches static assets for 7 days |
